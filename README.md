# Social Proof Section - Frontend Mentor Challenge

This is my solution to the [Social proof section challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/social-proof-section-6e0qTv_bA). 

##  What I Learned

During this project, I focused on writing cleaner, more maintainable code and improving my layout skills. My key takeaways include:

* **CSS Grid:** I utilized CSS Grid to efficiently structure and align the main layout elements (the header section and the ratings).
* **Design Tokens (CSS Custom Properties):** Instead of relying on random, hard-coded pixel values for margins and padding, I implemented a consistent spacing system using CSS variables (e.g., `--xs-space`, `--s-space`, `--m-space`). This made the styling process much smoother and the code much cleaner.

##  Continued Development (Current Issues)
